# Telegram-бот для городского новостного канала (с демо-песочницей)

Асинхронный бот на **Python 3.11+** и **aiogram 3.x** для приёма новостей от подписчиков («предложка» со склейкой альбомов), обработки обращений в поддержку и приёма заявок на рекламу.

## Переменные окружения (Railway Variables)

- `BOT_TOKEN` — токен бота от `@BotFather`
- `ADMIN_CHAT_ID` — ваш числовой Telegram ID или ID закрытой админ-группы
- `CHANNEL_ID` — числовой ID канала (`-100...`) или его `@username` (бот должен быть администратором канала с правом публикации)
- `DB_PATH` — путь к SQLite базе (если на Railway подключён Volume `/data`, база автоматически сохраняется в `/data/city_bot.db`)
